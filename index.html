Minecraft Java Server

Materials:
* Minecraft Java client software: https://www.minecraft.net/en-us/download
* Minecraft Java server software for Ubuntu Linux: https://www.minecraft.net/en-us/download
* A server or Promox VM running Ubuntu Server with at least 1 core and 2 GB of memory
* Ubuntu package installed for Minecraft Java server to run: "default-jre"
* Ubuntu package installed for remote management (usually installed by default): "openssh-server"
* Ubuntu package installed for grabbing the Minecraft Java server software: "wget"

Steps:
1) After install, get the ip address of your Minecraft java server: "ip a"
2) Remote into your Minecraft Java server with Powershell (Windows) or Terminal (MacOS/Linux): "ssh username@ip_address"
3) Make sure everything is up to date: "sudo apt update && sudo apt upgrade -y && sudo apt autoremove -y && sudo apt autoclean"
4) Install the Java Runtime Environment on the server: "sudo apt install default-jre -y"
5) Install the tool we will use to get the Minecraft Java server software: "sudo apt install wget -y"
6) Grab the Minecraft Java server software. On your client machine, open a browser and go to: https://www.minecraft.net/en-us/download and scroll down until you see " Minecraft server software Java Edition Server", click on it. then where it says download: right-click > Copy Link Address. It should end in "server.jar"
7) Next, on the Minecraft Java server that you are remoted into: "wget link_to_server.jar
8) You should now see a file called server.jar in your home directory. To see it: "ls -l"
9) Now, we are going to create a base folder for the server to live in: "mkdir JAVA"
10) Next, we are going to create a folder for the current version we download inside the base folder: "mkdir JAVA/1.x.x" where 1.x.x is the exact version
11) Now, we are going to copy the server.jar file into the version folder: "mv server.jar JAVA/1.x.x"
12) Let's navigate to the folder where the server.jar lives in: "cd JAVA/1.x.x"
13) Next, we will run it: "java -jar server.jar --nogui"
14) You should now see that you need to accept the eula. To do this: "nano eula.txt" > "eula=true" > "control + x, y, enter"
15) Next, let's re-run it: "java -jar server.jar --nogui" wait for it to finish then: "control + c"
16) Let's configure the serer: "nano server.properties" to open the config file. Add the features you want. To save it: "control + x, y, enter"
17) Let's make sure the server starts at boot: "sudo apt install screen -y"
18) Let's start a crontab: "crontab -e. > nano"
19) At the bottom paste this: @reboot /bin/bash -c "cd /home// && /usr/bin/screen -dmS java /usr/bin/java -jar server.jar --nogui"
20) To save the crontab: "control + x, y, enter"
21) Test by rebooting the server: "sudo reboot" and trying to connect via the Minecraft Java client
